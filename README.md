# homebrew-tap

The [Homebrew](https://brew.sh) tap for Thenvoi tools.

```sh
brew install thenvoi/tap/jam
```

(`thenvoi/tap` is shorthand for this repo, `thenvoi/homebrew-tap`.)

## What's here

- `Formula/` — generated formulae. `jam` installs the **`jam` CLI + `jamd` daemon**
  (the Band bridge for coding agents) as prebuilt binaries, side-by-side.
- `Casks/` — reserved for the future macOS desktop app (`jam-desktop`); not released
  yet.

## How it's maintained

**Don't hand-edit `Formula/*.rb`.** They're generated and committed automatically when a
`jam` release is tagged:

- `Formula/jam.rb` is generated by [`dist`](https://github.com/axodotdev/cargo-dist)
  (cargo-dist) from the jam repo's release workflow, which builds the macOS + Linux
  binaries, publishes a GitHub Release, and pushes the formula here.
- That job needs a token with write access to this repo (a fine-grained PAT or a GitHub
  App), provided to the jam release workflow as a secret.

Supported targets: macOS (Apple Silicon) and Linux (x86_64 / arm64).
