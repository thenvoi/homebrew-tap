# homebrew-tap

The [Homebrew](https://brew.sh) tap for Thenvoi tools.

```sh
brew install thenvoi/tap/jam
brew install --cask thenvoi/tap/jam-desktop
```

(`thenvoi/tap` is shorthand for this repo, `thenvoi/homebrew-tap`. If Homebrew
doesn't auto-detect the CLI cask, use `brew install --cask thenvoi/tap/jam`.)

## What's here

- `Casks/` — pre-compiled binaries (`jam`, the Band bridge CLI/daemon, and
  `jam-desktop`, the macOS tray app).
- `Formula/` — reserved for any from-source formulae (none yet).

## How it's maintained

**Don't hand-edit `Casks/*.rb`.** They're generated and committed automatically
when a `jam` release is tagged:

- `Casks/jam.rb` is generated by [GoReleaser](https://goreleaser.com); see
  `homebrew_casks:` in the jam repo's `.goreleaser.yaml`.
- `Casks/jam-desktop.rb` is generated by the jam repo's release workflow after
  the macOS desktop artifact is uploaded.

Those jobs need a `HOMEBREW_TAP_GITHUB_TOKEN` secret: a PAT with write access to
this repo.
